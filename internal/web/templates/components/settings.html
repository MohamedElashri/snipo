📖 View CSS Customization Guide

Snipo uses local vanilla CSS. Save and Apply updates the main snippets app; login and public pages use the built-in styles.

Common CSS Variables: 

--snipo-primary: Branded buttons and accents
--snipo-primary-hover: Branded button hover color
--snipo-background: Main page background
--snipo-card-background: Cards and dialogs
--snipo-color: General text color
--snipo-text-muted: Muted text color
--snipo-border-muted: General border color
--snipo-link-color: Link color
--snipo-link-hover: Link hover color
--snipo-input-bg: Native input background
--snipo-input-border: Native input border
--snipo-focus-color: Shared focus ring color
--snipo-danger: Error/delete color
--snipo-success: Success color

Example - Change accent color:

:root {
  --snipo-primary: #ff6b6b;
  --snipo-primary-hover: #e85555;
}

Links have separate colors. To change them in both UI themes:

:root[data-theme="light"],
:root[data-theme="dark"] {
  --snipo-link-color: #ff6b6b;
  --snipo-link-hover: #e85555;
}

Example - Custom sidebar styling:

[data-theme="dark"] .sidebar {
  background: linear-gradient(180deg, #1a1a2e 0%, #16213e 100%);
}

.snippet-card:hover {
  background: rgba(255, 107, 107, 0.1);
}

Existing custom CSS using --pico-* variables needs to be updated to Snipo variables. See the migration table in the full documentation.

💡 Tip: Use browser DevTools (F12) to inspect elements. See full documentation.
